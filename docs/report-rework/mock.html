Severity comes from deterministic rules. The model's risk score is an input, and the rules can only raise or cap it. Each step is recorded so the result can be reproduced.

What would change the assessment

  1. Trace SMS call sites. If no SMS API is reached from an entry point, the sms_fraud rule lacks its basis and the rating should drop.
  2. Verify the four endpoints. Check DNS, reputation and any live response, and record the date. If they resolve to benign services, the C2 rule lacks its basis.
  3. Re-check SDK values. Correct manifest parsing affects only the metadata, but it is a sign the parser is unreliable on this file.
