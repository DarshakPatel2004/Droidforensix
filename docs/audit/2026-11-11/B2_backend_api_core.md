# B2 — Backend API + core audit (backend/* minus intel modules, droidforensix/*)

Scope: every file in my slice, read line by line. Experiments were read-only and ran in scratchpad temp dirs (`scratchpad/audit/exp/*.py`): FastAPI TestClient with DROIDFORENSIX_TESTING=1 and WORK_DIR/UPLOADS_DIR set to temp dirs; androguard and ELFBreaker run on local sample APKs.

### Already-known items (confirmed, not re-reported)
- routers/dissection.py:75-77 `rglob("file.apk")` fallback returns another sample's APK. Confirmed.
- routers/jobs.py:266 writes "queued" into `upload["status"]`, not `sample_status`. The idempotency guard (224) and `/status` (279) miss it. Confirmed, and the impact is worse than described: the frontend polls `/status` with uploadId (App.jsx:228), gets a 404 in the gap before the worker thread starts, and `useSampleStatus` treats a 404 as final, so polling stops.
- All routes are `async def` and call sync `load_result`/`identify_family`. Confirmed (also `_get_sample_apk_path` rglob, analyst_store sqlite, and `/dissection/strings` full-file read).
- `load_all_results` uses a 300 s TTL that is never invalidated, while the docstring says 5 s (transformers.py:27, 129). Confirmed.
- dissection.json is written non-atomically (routers/dissection.py:119-122). Confirmed.
- `/api/analysis/full` and `/androguard-only` have no size or magic checks and block the event loop. Confirmed (B2-06 adds the subdirectory overwrite).
- The default bind is 0.0.0.0 with no auth (main.py:160, config.py:90, cli.py:105). Confirmed.
- `asyncio.get_event_loop()` is used inside coroutines (jobs.py:231, samples.py:530, dissection.py:128 and others, reports.py:37/159, intel.py:42). Confirmed.

### Checked and found OK
- sample_id validation: every route that joins WORK_DIR/sample_id reaches `validate_sample_id`, either through `load_result` (transformers.py:92-95) or `_require_sample`/custody. `/status` falls through to `load_result`. `explain-chain` does no join (see B2-16).
- Zip-slip: nothing in this slice extracts archive entries to disk.
- XXE: no direct XML parsing in this slice. The manifest comes from androguard's AXML parser.
- analyst_store: opens a new sqlite connection per call, so it is thread-safe, and pydantic bounds tags and notes.
- realtime: broadcast iterates a snapshot, and the emitter uses `run_coroutine_threadsafe` correctly.
- class-name path params flow only into in-memory DEX lookups; none are used in a filesystem path.
