# Frontend audit: DroidForensix `frontend/` (slice F)

Read-only. I read every tracked file under `frontend/src` in full, plus `index.html`, `vite.config.js`, `package.json` and `eslint.config.js`. I also ran:
- `npm run lint`: clean.
- `npx vitest run`: 45 files, 287 tests, all pass.
- `vite build` (output to the scratchpad):
  - The index chunk is 283 KB: react-dom 19, react-router 7 and the eagerly loaded app shell.
  - ThreatIntelView is 169 KB: leaflet, react-leaflet and leaflet.css.
  - recharts is tree-shaken out, because its only user (DEXTab) is unreachable.

**XSS verdict:** I found no live XSS.
- `SmartDissection.jsx:563` uses dangerouslySetInnerHTML, but it escapes `& < >` before wrapping fixed keywords. That is correct for text context.
- `ClassSourceViewer.jsx:24-34` post-processes innerHTML. It only re-inserts markup that hljs already escaped, so it can garble the source view but cannot inject anything (see F-24).
- The only data-driven href without validation is in dead code: `CommunityIntelTab.jsx:104` (F-41).
- `index.html` sets no CSP.

**More hardcoded `localhost:8000`** (beyond the 5 already known):
- `App.jsx:28` (WS_URL)
- `ManifestView.jsx:84`
- `SampleSearch.jsx:17`
- `UploadPanel.jsx:249,276` (user-facing text)

`api/client.js:11` is the correct VITE_API_URL fallback. The Vite proxy for `/api` and `/ws` (`vite.config.js:8-11`) is never used, because App passes absolute URLs.
