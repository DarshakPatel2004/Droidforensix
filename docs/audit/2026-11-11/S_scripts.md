# Audit slice: `scripts/` (59 tracked files, 16,364 lines)

Scope: every file from `git ls-files scripts`, read line by line. Read-only: nothing was run against samples or the network. I ran local checks only: LIEF enum values, symbol greps, and gitignore checks.
Environment facts used as evidence: `.venv` has lief 1.0.0, unicorn 2.1.4 and capstone 5.0.7. `requirements-lock.txt` has none of lief, unicorn, capstone, pycryptodome or androguard.
Call context: `analysis/step0_master_key.py:96-118` imports `unpack.java_route/native_route` **in-process** from the pipeline. It passes `wd / "master_key"`, where `wd` is the **root** work dir (`analysis/pipeline.py:461`, `step0_master_key.py:335`). That makes unpack/emulate part of the product path for every packed upload.

Tags: CONFIRMED = traced through the code (plus a local check where one is noted). PLAUSIBLE = depends on external data, a library version or an API.
