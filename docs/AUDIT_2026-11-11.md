## Critical and high-priority findings

Ordered by urgency, with the agent IDs that point to the full write-up.

**Safety and security**
1. **Live DNS and IP lookups on C2 hosts from the threat-intel view** (B1-12/13): sends malware C2 IPs to an external service over plain HTTP, which can tip off operators.
2. **Port scan of IPs taken from malware, with no opt-in** (S, R1): `forensic_pipeline.py:899-928`.
3. **Files deleted by mistake in download scripts** (S, R2/R3): renames then deletes the first `.apk` in the shared samples folder when a hash check fails.
4. **Unauthenticated server bound to `0.0.0.0`** (B2 / earlier audit): anyone on the network can upload, read reports, and spend your LLM keys.
5. **No origin check on `/ws`** (B2-07, reproduced): any website can receive analysis events.
6. **One upload can overwrite another's APK** (B2-06, reproduced): a filename like `<upload_id>/file.apk` passes the path check.
7. **C2 allowlist lets real C2 through as benign** (A1-03, B1-16): suffix matching on Firebase, App Engine, raw GitHub, S3 and similar hosts. Reproduced.
8. **Decompression of hostile `.so` files without a size check** (B2-02, B1-18): zip or zlib bomb risk; not reproduced.

**Correctness that changes verdicts or results**
9. **Pipeline steps 11, 12, 14, 15 and 17 compute nothing on real input** (A2 H2–H4, M1): wrong keys and types between `pipeline.py` and the steps. CI passes because the tests use hand-built inputs.
10. **Step 14 will crash once step 11's input is fixed** (A2 H5): `urlparse().port` raises on common URLs. Fix 9 and 10 together.
11. **Packing check looks for `.text`, but sections are keyed `classes.dex`** (A2 H6): random 600 KB DEX reported as not packed.
12. **Crash on certain JWT-shaped strings** (A2 H1): unhandled `UnboundLocalError` kills the whole pipeline.
13. **Bare IP and IP:port C2 dropped in step 2** (A1-01, reproduced): `45.77.12.9:7771` classed as noise.
14. **Decoded payloads yield C2 only from URLs** (A1-02): bare IPs and domains from base64/XOR payloads are lost.
15. **LLM verdict caps overwrite high-severity results** (A1-04, A1-05, reproduced): a note containing "C2" trips a keyword check; the secrets rule's high/70 is overwritten with medium/30.
16. **Wrong key in step 9 inflates verdicts after a step 8 failure** (A1-06, reproduced): large benign apps read as "tiny DEX".
17. **Family attribution is in-sample** (B1-01, E2): 198 of 352 predictions come from a knowledge base mined from the same ground truth. Leak-free baseline is 35.5%.
18. **LLM sees attacker-controlled strings verbatim and is not checked against the candidate list** (B1-02): contradicts the README's multiple-choice claim.
19. **Strict knowledge-base gate bypassed by the LLM fallback** (B1-03, reproduced).
20. **`family.json` never invalidated**, so an LLM outage caches "unknown" permanently (B1-04, reproduced).
21. **Generic patterns name families at 0.75–0.85 confidence** (B1-05, reproduced): Flurry analytics becomes FluBot; "tea" becomes TeaBot.
22. **Code-analysis view returns nothing on real samples** (B2-03, reproduced): expects Java source, gets Androguard disassembly.
23. **Every native library rated CRITICAL** (B2-05, reproduced): ELF magic and "su" substring match.
24. **Leakage guard checks the wrong set** (E5): `scripts/evaluate_malben.py:42` compares against a 222-row file, not the 509-row training set. The 97.3% is not inflated by leakage (overlap computed as 0), but the guard would not catch it next time.
25. **Headline numbers not reproducible from any commit** (E6): model, report, manifest and split files are untracked.
26. **Holdout confound** (E3, see README): Drebin malware vs. current F-Droid benign.
27. **Evaluated model differs from the shipped default** (E4): CLI defaults to the older model at 0.5.
28. **Validation false-positive script biases its own numbers** (S R9): benign-domain regexes unanchored; re-runs duplicate records.
29. **`classify_fast` leaks temp directories** (A2 M7): batch runs fill the disk.

**Delivery and CI**
30. **CI red on `main`** (T-01): 8 most recent runs failed, most recent 2026-11-09. PRs #9–#11 merged anyway.
31. **Required test files are git-ignored** (T-02): `.gitignore:62` hides `data/known_bad_certificates.json`; `.gitignore:230` hides `rto_analysis/*`. Causes most CI failures; step 16's cert database silently loads empty on a clean clone.
32. **Path check only works on Windows** (T-03): CI on Linux accepts `..\..\pwned.apk`.
33. **Packer step fails silently on a clean install** (S P14): `lief`, `unicorn`, `capstone` and `pycryptodome` missing from `requirements-lock.txt`.
34. **Emulator does not run the code it should** (S P1–P4): constructors called at twice the base address; relocations no-op under current LIEF; hook fires N+1 times. Traced, not run.
35. **Unpacker reports RECOVERED without validating** (S P5): `validate_dex` computed and ignored.

**Frontend**

37. **Index keys on reordered lists attribute code to the wrong class** (F-03, verified at `SmartDissection.jsx:210-212`).

## Medium and low findings

Per-area reports list all of them with file:line, the failure scenario, and a suggested minimal fix. The main groups:

- **Performance:** most routes block the event loop (B2, B1-07); string-reference lookup re-parses every DEX per class (B2-04, about 60 s on a 570-class APK); the full APK is re-hashed on every request (B2-10); signature matching runs about 300 regex scans over the whole string blob (B1-07).
- **Caching:** failed class listings and failed LLM summaries are cached permanently (B2-11, B2-12); the `/api/samples` cache never invalidates (B2-08 area, transformers).
- **Robustness:** one null field breaks `/api/samples`, `/api/clusters` and `/threat-summary` for the whole corpus (B2-08, reproduced); zip-bomb memory (B2-02).
- **Test quality:** some tests cannot fail (T-05), e.g. an assertion of the form `... or True`; most dissection and sample-route tests always skip in CI (T-06); the isolation fixture misses three modules (T-08).
- **Dead code:** about 2,900 lines of frontend components with no importer (F-22), and several unused scripts (S delete/merge list).
- **Repository hygiene:** 105 MB of model files tracked in git (`evaluation/family_classifier_clean.pkl` 16 MB, `analysis/family_ml.pkl` 11 MB).
- **Documentation:** `CLAUDE.md` says `run_pipeline_direct.py` is missing; it exists at `scripts/debug/`. `run_full_pipeline.ps1` calls it from the wrong path.
